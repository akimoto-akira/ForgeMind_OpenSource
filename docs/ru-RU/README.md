# Документация ForgeMind (русский)

ForgeMind — платформа управления игровыми движками на основе MCP: через протокол MCP предоставляет ИИ-клиентам управление проектами Unreal Engine, чтение ассетов и операции запуска/сборки/редактирования. Текущая реализация — UE (5.0–5.8); архитектура платформы расширяема на другие движки.

> Эта документация посвящена части **open source**: `OpenSource\` (хост и плагины), `UEProject\` (примерный проект) и `tests\` (тесты). Коммерческие функции (генерация ассетов DSL, реализация коммерческих лицензий) описаны только в общем виде и не входят в версию open source. OpenSource сохраняет необходимые лицензионные абстракции и открытую реализацию.

## Обзор границ open source

```
OpenSource\
  ForgeMindServer               MCP-хост (4 встроенных инструмента + загрузка плагинов + TCP bridge)
  ForgeMind.OfflineEngineKit    Инструменты движка/проекта/запуска/сборки/редактирования (плагин)
  ForgeMind.Assets              Офлайн-чтение .uasset (плагин)
  ForgeMind.Knowledge           Поиск знаний (плагин)
  ForgeMind.Scan.Abstractions   Абстракции данных сканирования и провайдеров
  ForgeMind.Scan                Чтение и упаковка SPK
  ForgeMind.Scan.Unreal         Реализация сканирования Unreal Engine
  ForgeMind.EngineScanner       Автономный CLI-сканер, генерирующий .spk напрямую
  ForgeMind.Speedy              Низкоуровневая база SPK
UEProject\ForgeMind_5_0         Примерный проект UE (5.0–5.8)
tests\                          Публичные модульные тесты + интеграционные тесты сервера
```

## Лицензия

Содержимое части open source лицензировано под Apache-2.0. Коммерческие модули не являются частью open source и предоставляются по отдельной коммерческой лицензии.
