# Решение проблем ForgeMind

В этом документе собраны частые проблемы и их решения. Перед устранением проблем убедитесь, что версия окружения соответствует требованиям `getting-started.md` §1.

## 1. Сервер не запускается

- **Порт занят**: попробуйте `--port` с другим портом или измените `FORGEMIND_PORT`; проверьте, запущен ли процесс (`netstat -ano | findstr 8765`).
- **Ошибка сборки**: собирайте отдельные проекты, а не `ForgeMind.sln` напрямую (содержит коммерческие ссылки, см. `development-guide.md` §1).
- **Ошибка конфигурации**: удалите `%USERPROFILE%\.forgemind\settings.json` (конфигурация читается при старте; после удаления создаётся конфигурация по умолчанию) — перед удалением сделайте резервную копию.

## 2. Клиент не может подключиться

- Проверьте адрес сервера: по умолчанию `http://127.0.0.1:8765/mcp`; параметры `--port` / `FORGEMIND_PORT` должны совпадать.
- Проверьте, запущен ли сервер, и попробуйте `curl http://127.0.0.1:8765/mcp`.
- Проверьте настройки клиента (mcpServers): формат `{ "mcpServers": { "forgemind": { "url": "..." } } }`.

## 3. Плагин не загружается

- Проверьте расположение: DLL + `.manifest.json` с тем же именем в каталоге `plugins\` хоста (или каталоге, заданном через `FORGEMIND_PLUGINS_DIR`); проверьте имя DLL.
- Проверьте манифест (формат JSON, записи зависимостей и т.п.) и перезапустите хост.
- Проверьте, появляется ли 'load plugin failed' в логе хоста, и действуйте соответственно (игнорируется только данный плагин).

## 4. Bridge не подключается

- Проверьте, существует ли `bridge.json` в `%USERPROFILE%\.forgemind\` и содержит ли правильные порт и учётные данные; затем перезапустите редактор.
- Проверьте, запущен ли хост; адаптер переподключается с экспоненциальным backoff.
- В редакторе откройте лог вывода плагина `ForgeMindForUE` (Output Log / LogForgeMind), чтобы увидеть ошибку.

## 5. Инструмент возвращает ошибку авторизации

- Операции, связанные с движком, подчиняются `ServerPermissionChecker`. Проверьте конфигурацию разрешений в настройках сервера (разрешённые операции).
- `settings` может показывать/изменять конфигурацию; после изменения перезапустите хост.

## 6. Медленный поиск знаний / SPK

- Сгенерируйте пакет индекса SPK с помощью `ForgeMind.EngineScanner <spkPath>` и убедитесь, что источник пакета индекса указывает на правильный пакет.
- Большой проект: проверьте размер индекса и фильтры (каталог/тип), задайте соответствующие источники и интервалы.
