# Дорожная карта ForgeMind

Направление представлено в публичной перспективе, по вехам; конкретные сроки определяются релизами.

## Ближайший период

- **Завершение open source среза**: объединить скрипты сборки и инструкции по подключению в одну команду, чтобы снизить порог входа для новых контрибьюторов.
- **Синхронизация документации**: поддерживать страницы в `docs\zh-CN\` в соответствии с изменениями исходного кода, обеспечивая согласованность с публичным срезом.
- **Покрытие тестами**: расширить кейсы `ForgeMind.PublicTests` и `ForgeMindServerTest` (команды моста, сканирование, граничные сценарии SPK).

## Средний период

- **Расширение адаптеров движков**: на основе существующего адаптера UE (5.0–5.8) исследовать интеграцию других движков / редакторов (аналогичный протокол моста).
- **Усиление сканирования и knowledge**: улучшить покрытие парсинга DocumentEngine для хедеров / блюпринтов / файлов правил и оптимизировать эффективность и инкрементальное обновление упаковки SPK.
- **Экосистема плагинов**: доработать API плагинов и спецификацию манифеста, поддержать более богатые сторонние плагины.

## Долгосрочный период

- **Открытие документации использования DSL**: когда коммерческое DSL стабилизируется, в соответствии со стратегией продукта может быть опубликована часть документации по использованию, примеров и обучающих материалов; реализация DSL, Translator, IR-правила и логика генерации ассетов остаются коммерческими модулями.
- **Платформа**: позиционировать ForgeMind как мультидвижковую платформу управления MCP, консолидируя протокол и независимые от движка слои абстракции.

> Направление коммерческой версии (система авторизации, enterprise-поддержка и т.д.) не раскрывается в этой публичной дорожной карте: обращайтесь к издателю.
