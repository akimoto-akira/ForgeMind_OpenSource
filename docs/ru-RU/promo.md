# Публичная коммуникация ForgeMind

## Презентация в одно предложение

ForgeMind — это платформа управления игровым движком через интерфейс MCP: предоставляет AI-клиентам управление проектами Unreal Engine, чтение ассетов, запуск / сборку / операции в редакторе, позволяя AI работать с движком как с инструментом.

## Ключевые особенности

- **Нативная интеграция MCP**: стандартный протокол MCP (HTTP / stdio), основные AI-клиенты подключаются и работают сразу.
- **Самостоятельно собираемый open source срез**: публичный репозиторий содержит хост, все плагины open source, пример проекта UE и тесты; с Apache-2.0 можно самостоятельно собирать и расширять.
- **Архитектура адаптеров движков**: хост и движок разделены через локальный TCP bridge, расширяемо за пределы UE.
- **Офлайн-чтение ассетов**: парсинг структуры `.uasset` без открытия редактора, в сочетании с индексом сканирования (SPK) для функций поиска знаний.
- **Расширение функций плагинами**: хост интегрирует только минимальный набор инструментов; функции расширяются плагинами, границы ясны и сокращаемы.

## Коммерческая версия (одно предложение)

Коммерческая версия предлагает на базе OpenSource генерацию ассетов DSL, коммерческую авторизацию и enterprise-поддержку; детали синтаксиса DSL и режимов авторизации — по запросу у издателя.

## Правила публичной коммуникации

- Не обещайте невыпущенные функции; дорожная карта обязательна согласно `roadmap.md`.
- Не очерняйте аналогичные инструменты; не раскрывайте вовне внутренние детали коммерческих модулей (алгоритмы авторизации, внутренние IR-правила DSL и т.д.).
- Для поведения, связанного с исходным кодом, всегда ссылайтесь на публичный срез; неопределённые элементы помечайте как «ожидает подтверждения».
