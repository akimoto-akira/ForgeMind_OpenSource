# Справочник инструментов ForgeMind

Все инструменты разделены на «встроенные в хост» и «внедряемые плагинами». Текущая версия open source содержит 13 инструментов MCP. Коммерческий плагин может предоставлять другие инструменты (генерация ассетов DSL и т.п., см. §3; не входят в список open source).

## 1. Встроенные инструменты хоста

Хост (`OpenSource\ForgeMindServer`) содержит следующие инструменты без плагинов:

| Инструмент | Описание |
|---|---|
| `settings` | Чтение/запись конфигурации сервера (`McpSettingsManager`, немедленная персистентность) |
| `get_task_result` | Запрос результата долгих задач (launch / build и т.п.) |
| `list_executing_tasks` | Список текущих долгих задач |
| `cleanup_tasks` | Очистка записей завершённых задач |

## 2. Инструменты, внедряемые плагинами

Плагины внедряют инструменты через `PluginContext.RegisterTool` в `OnLoad`; они появляются после подключения клиента. После сборки поместите DLL плагина + `.manifest.json` с тем же именем в каталог `plugins\` хоста (или каталог, заданный через `FORGEMIND_PLUGINS_DIR`).

### ForgeMind.OfflineEngineKit (7)

| Инструмент | Описание |
|---|---|
| `engine` | Запрос локально установленных движков (Launcher / сборки из исходников, включая версию и имя приложения) |
| `project` | Запрос/управление проектами UE (идентификация файла проекта, запрос информации о проекте) |
| `project_files` | Список файлов проекта (фильтр каталога/типа) |
| `switch_version` | Смена версии проекта на указанный движок (через UnrealVersionSelector) |
| `launch` | Запуск редактора или упакованных исполняемых файлов (поддерживается конфигурация отладки) |
| `build` | Сборка проекта (цель по умолчанию / цель Editor) |
| `editor` | Операции в редакторе (сцена, viewport, ассеты и т.п., отправляются через bridge) |

Схемы параметров подчиняются `GetParameterSchema()` из исходного кода каждого инструмента (`OpenSource\ForgeMind.OfflineEngineKit\*.cs`). Некоторые операции движка подчиняются разрешениям `ServerPermissionChecker`.

### ForgeMind.Assets (1)

| Инструмент | Описание |
|---|---|
| `asset` | Офлайн-чтение структуры `.uasset` (имена, объекты, свойства, графы блюпринтов, запрос по графу/свойству) |

Реализация основана на `UAsset\UAssetSerializer` / `BlueprintGraphReader` и т.п. (`OpenSource\ForgeMind.Assets\`).

### ForgeMind.Knowledge (1)

| Инструмент | Описание |
|---|---|
| `knowledge` | Поиск знаний: запрос записей знаний проекта/движка (источники: источник каталога `FolderKnowledgeSource`, источник пакета индекса SPK `IndexPackSource`) |

Реализация в `OpenSource\ForgeMind.Knowledge\Knowledge\`.

## 3. Инструменты коммерческой версии (обзор)

Коммерческая версия может добавлять генерацию ассетов DSL и связанные инструменты запросов, внедряемые коммерческим плагином. Конкретные имена, API и функции DSL подчиняются коммерческой документации. OpenSource не содержит ни одного инструмента DSL.

## 4. Соглашения о вызовах инструментов

- Инструменты долгих задач возвращают ID задачи. Результат получается через `get_task_result`.
- Ошибки инструментов возвращают `ToolResult` ошибки (отображается клиенту напрямую).
- Описания и схемы параметров инструментов соответствуют тому, что показывает `tools/list` MCP, и согласованы с исходным кодом.
