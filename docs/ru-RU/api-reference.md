# Справочник API ForgeMind

В этом документе описана публичная часть внешних интерфейсов ForgeMind: подключение MCP, протокол bridge, контракты инструментов и механизм долгих задач. Коммерческие функции (DSL) описаны только в общем виде в §6.

## 1. Подключение MCP

- **Режим HTTP** (по умолчанию): `http://127.0.0.1:8765/mcp`, Streamable HTTP (совместим со старым SSE). Процесс хоста резидентный; одно подключение обслуживает несколько клиентских сессий.
- **Режим stdio**: `ForgeMindServer.exe --stdio`, для каждого клиента запускается отдельный процесс.
- Порт: `--port N` > переменная окружения `FORGEMIND_PORT` > по умолчанию 8765.

Поддерживаемые стандартные методы MCP: `initialize`, `tools/list`, `tools/call`, `notifications/cancelled` и т.п. Схема инструментов предоставляется через `ITool.GetParameterSchema()`.

## 2. Контракт инструментов

Инструменты сервера реализуют унифицированный интерфейс (`OpenSource\ForgeMindServer\Compat\ITool.cs`):

- `Name` / `DisplayName`: идентификатор и отображаемое имя инструмента;
- `Description`: описательный текст для ИИ-клиента;
- `GetParameterSchema()`: объявление параметров (стиль JSON Schema);
- `Execute(Guid callerId, Dictionary<string, object> parameters)`: возвращает `ToolResult` после выполнения (результат успеха или сообщение об ошибке).

Поток вызова: клиент `tools/call` → хост находит `ITool` → валидация параметров → `Execute` → возврат результата. Инструменты, требующие функций движка, внутренне отправляют команды через TCP bridge.

## 3. Протокол bridge (хост ↔ адаптер движка)

- Транспорт: локальный TCP. Формат кадра = 4-байтовый префикс длины + JSON-конверт (`BridgeMessage`, см. `Bridge\BridgeMessage.cs` / `FrameCodec.cs`).
- Обнаружение и аутентификация: адаптер читает `%USERPROFILE%\.forgemind\bridge.json` (содержит host, порт и учётные данные), выполняет подключение → handshake → цикл сообщений.
- Семантика команд: запрос содержит имя команды и параметры. Сервер маршрутизирует команду в реализацию адаптера; ответ содержит код состояния, сообщение и данные. Команды на стороне движка выполняются в главном потоке движка (игровой поток UE).
- Жизненный цикл: хост начинает слушать bridge при старте. Адаптер переподключается с экспоненциальным backoff после разрыва.

## 4. Механизм долгих задач

- Долгие задачи (`launch`, `build` и т.п.) выполняются асинхронно и не блокируют вызов инструмента.
- Связанные встроенные инструменты:
  - `get_task_result`: запрос результата задачи;
  - `list_executing_tasks`: список текущих задач;
  - `cleanup_tasks`: очистка записей задач.
- Внутренне `LongTaskManager` управляет жизненным циклом задач (`LongTaskManager.cs` / `LongTaskTools.cs`).

## 5. Встроенные инструменты (часть хоста, без плагинов)

| Инструмент | Описание |
|---|---|
| `settings` | Чтение/запись конфигурации сервера (`McpSettingsManager`, немедленная персистентность) |
| `get_task_result` | Запрос результата долгих задач |
| `list_executing_tasks` | Запрос текущих задач |
| `cleanup_tasks` | Очистка записей задач |

Полный список инструментов, внедряемых плагинами, — в `tools-reference.md`.

## 6. Коммерческие функции (DSL, обзор)

- OpenSource предоставляет **контракты расширения DSL** (интерфейсы и реестры `ParserFactory` / `ITranslator` / `TranslatorRegistry` / `IIrConverter` / `IrConverterRegistry` / `DiagnosticReporter` в `ForgeMindServer\DSL\` публичны). Конкретные реализации синтаксиса DSL, Parser, Translator, правил IR и логики генерации ассетов принадлежат Commercial и отсутствуют в OpenSource.
- Инструменты DSL внедряются коммерческим плагином. Конкретные имена и API подчиняются коммерческой документации. Список инструментов OpenSource не содержит ни одного инструмента DSL.

| Функция | Принадлежность |
|---|---|
| Интерфейсы расширения DSL | OpenSource ✅ |
| Parser DSL | Commercial 🔒 |
| Translator DSL | Commercial 🔒 |
| Правила IR | Commercial 🔒 |
| Логика генерации ассетов | Commercial 🔒 |

## 7. Примечания о совместимости

- Формат кадра протокола bridge и схемы инструментов подчиняются этому документу. Изменения, ломающие совместимость, будут анонсированы заранее с примечанием о миграции.
