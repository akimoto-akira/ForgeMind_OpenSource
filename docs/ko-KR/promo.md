# ForgeMind 프로모

## 한 줄 소개

ForgeMind는 MCP를 인터페이스로 하는 게임 엔진 제어 플랫폼입니다: MCP 프로토콜을 통해 Unreal Engine의 프로젝트 관리, 에셋 읽기, 실행/빌드/에디터 조작을 AI 클라이언트에 공개해 AI가 도구처럼 엔진을 조작하게 합니다.

## 핵심 하이라이트

- **네이티브 MCP 연동**: 표준 MCP 프로토콜(HTTP / stdio), 주류 AI 클라이언트에서 바로 사용 가능.
- **셀프 빌드 가능한 오픈소스 슬라이스**: 공개 저장소에 호스트, 전체 오픈소스 플러그인, 샘플 UE 프로젝트, 테스트 포함, Apache-2.0, 셀프 빌드·확장 가능.
- **엔진 어댑터 아키텍처**: 호스트와 엔진이 로컬 TCP 브리지로 느슨하게 결합, UE 외 엔진으로 확장 가능.
- **오프라인 에셋 읽기**: 에디터를 열지 않고 `.uasset` 구조를 파싱. 스캔 인덱스(SPK)와 결합해 지식 검색 기능 제공.
- **플러그인식 기능 주입**: 호스트는 최소 도구 세트만 포함, 기능은 플러그인이 확장, 경계가 명확하고 커팅 가능.

## 상용 버전(한 줄)

상용 버전은 OpenSource 위에 DSL 에셋 생성, 상용 라이선스 기능, 엔터프라이즈 지원을 제공합니다. DSL 문법 세부 사항과 라이선스 조항은 배포자에게 문의하세요.

## 대외 규율

- 미출시 기능을 약속하지 않음. 로드맵은 `roadmap.md`를 따름.
- 동종 도구를 폄하하지 않음. 상용 모듈 내부(라이선스 알고리즘, DSL 내부 IR 규칙 등)를 대외 공개하지 않음.
- 소스 코드 동작 관련은 항상 공개 슬라이스에 따르며 불확실한 항목은 '확인 필요'로 표시.
