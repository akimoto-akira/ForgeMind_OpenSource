# ForgeMind 로드맵

방향은 공개 관점에서 서술하며 마일스톤 순으로 나열합니다. 구체적인 일정은 릴리스에 따릅니다.

## 단기

- **오픈소스 슬라이스 정비**: 빌드 스크립트와 원클릭 공동 디버깅 절차를 완성해 신규 기여자의 진입 비용을 낮춤.
- **문서 동기화**: 소스 코드 변경에 따라 `docs\zh-CN\`의 각 문서를 유지하며 공개 슬라이스와 일치를 유지.
- **테스트 커버리지**: `ForgeMind.PublicTests`와 `ForgeMindServerTest` 케이스(브리지 명령, 스캔, SPK 경계 시나리오) 확충.

## 중기

- **엔진 어댑터 확장**: 기존 UE 어댑터(5.0–5.8)에 더해 더 많은 엔진/에디터 연동 탐색(동형 브리지 프로토콜).
- **스캔과 지식 기능 강화**: DocumentEngine의 헤더 파일 / 블루프린트 / 규칙 파일 파싱 커버리지를 높이고 SPK 패키징 효율과 증분 업데이트 개선.
- **플러그인 생태계**: 플러그인 API와 매니페스트 규격을 정비해 더 풍부한 서드파티 도구 플러그인 생태계 지원.

## 장기

- **오픈 DSL 사용 문서**: 상용 DSL이 안정화된 후 제품 전략에 따라 일부 사용 문서, 샘플, 교육 콘텐츠를 공개할 가능성. DSL 구현, Translator, IR 규칙, 에셋 생성 로직은 상용 모듈로 유지.
- **플랫폼화**: ForgeMind를 다중 엔진 범용 MCP 제어 플랫폼으로 자리매김하고 엔진 비의존 프로토콜과 추상 계층을 축적.

> 상용 버전 방향(라이선스 시스템, 엔터프라이즈 지원 등)은 이 공개 로드맵에서 펼치지 않습니다. 배포자에게 문의하세요.
