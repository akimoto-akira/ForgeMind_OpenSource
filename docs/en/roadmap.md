# ForgeMind Roadmap

Directions are stated from a public perspective, ordered by milestone; specific scheduling is subject to releases.

## Near Term

- **Open-source slice refinement**: complete build scripts and one-click joint debugging instructions to lower the onboarding cost for new contributors.
- **Documentation sync**: maintain each document in `docs\zh-CN\` as the source code changes, ensuring consistency with the public slice.
- **Test coverage**: expand `ForgeMind.PublicTests` and `ForgeMindServerTest` cases (bridge commands, scanning, SPK boundary scenarios).

## Mid Term

- **Engine adapter expansion**: on top of the existing UE adapter (5.0–5.8), explore more engine / editor integrations (isomorphic bridge protocol).
- **Scan and knowledge capability enhancement**: improve DocumentEngine's parsing coverage of header files / blueprints / rule files, and improve SPK packaging efficiency and incremental updates.
- **Plugin ecosystem**: improve plugin API and manifest specifications, supporting a richer ecosystem of third-party tool plugins.

## Long Term

- **Open DSL usage documentation**: after commercial DSL stabilizes, some usage documentation, examples and teaching content may be made public according to product strategy; DSL implementation, Translator, IR rules and asset generation logic remain commercial modules.
- **Platformization**: position ForgeMind as a multi-engine general-purpose MCP control platform, consolidating engine-agnostic protocols and abstraction layers.

> Commercial edition directions (licensing system, enterprise support, etc.) are not expanded in this public roadmap; contact the publisher.
