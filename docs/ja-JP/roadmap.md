# ForgeMind ロードマップ

方向性は公開視点で述べ、マイルストーン順に並べます。具体的なスケジュールはリリースに従います。

## 短期

- **オープンソーススライス整備**：ビルドスクリプトとワンクリック共同デバッグ手順を完成し、新規コントリビューターの参入コストを低減。
- **ドキュメント同期**：ソースコードの変更に伴い `docs\zh-CN\` の各ドキュメントを保守し、公開スライスと一致を維持。
- **テストカバレッジ**：`ForgeMind.PublicTests` と `ForgeMindServerTest` のケース（ブリッジコマンド、スキャン、SPK 境界シナリオ）を拡充。

## 中期

- **エンジンアダプタ拡張**：既存の UE アダプタ（5.0–5.8）に加え、より多くのエンジン / エディタ統合を探索（同型ブリッジプロトコル）。
- **スキャンとナレッジ機能強化**：DocumentEngine のヘッダーファイル / ブループリント / ルールファイル解析カバレッジを向上し、SPK パッケージング効率と増分更新を改善。
- **プラグインエコシステム**：プラグイン API とマニフェスト仕様を整備し、より豊かなサードパーティツールプラグインエコシステムをサポート。

## 長期

- **オープンな DSL 使用ドキュメント**：商業 DSL が安定した後、製品戦略に応じて一部の使用ドキュメント、サンプル、教育コンテンツを公開する可能性があります。DSL 実装、Translator、IR ルール、アセット生成ロジックは商業モジュールのまま。
- **プラットフォーム化**：ForgeMind を複数エンジン汎用の MCP 制御プラットフォームとして位置づけ、エンジン非依存のプロトコルと抽象層を蓄積。

> 商用版の方向性（ライセンスシステム、エンタープライズサポートなど）はこの公開ロードマップでは展開しません。公開元に連絡してください。
