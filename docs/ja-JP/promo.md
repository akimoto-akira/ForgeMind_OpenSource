# ForgeMind プロモ

## 一言紹介

ForgeMind は MCP をインターフェースとするゲームエンジン制御プラットフォームです：MCP プロトコルを通じて Unreal Engine のプロジェクト管理、アセット読み取り、起動 / ビルド / エディタ操作を AI クライアントに公開し、AI がツールのようにエンジンを操作できるようにします。

## コアハイライト

- **ネイティブ MCP 接続**：標準 MCP プロトコル（HTTP / stdio）、主流の AI クライアントがすぐに利用可能。
- **セルフビルド可能なオープンソーススライス**：公開リポジトリにはホスト、全オープンソースプラグイン、サンプル UE プロジェクト、テストが含まれ、Apache-2.0、セルフビルド・拡張可能。
- **エンジンアダプタアーキテクチャ**：ホストとエンジンはローカル TCP ブリッジで疎結合、UE 以外のエンジンへ拡張可能。
- **オフラインアセット読み取り**：エディタを開かずに `.uasset` 構造を解析。スキャンインデックス（SPK）と組み合わせてナレッジ検索機能を提供。
- **プラグイン式機能注入**：ホストは最小ツールセットのみ同梱、機能はプラグインが拡張、境界が明確でカット可能。

## 商用版（一言）

商用版は OpenSource の上に DSL アセット生成、商用ライセンス機能、エンタープライズサポートを提供します。DSL 構文の詳細とライセンス条項は公開元に連絡してください。

## 対外規律

- 未リリース機能を約束しない。ロードマップは `roadmap.md` に従う。
- 同種ツールを貶めない。商業モジュール内部（ライセンスアルゴリズム、DSL 内部 IR ルールなど）を対外的に公開しない。
- ソースコードの動作に関わるものは常に公開スライスに従い、不確定項目は「待確認」と標記。
