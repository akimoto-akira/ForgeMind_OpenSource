# ForgeMind 對外宣傳

## 一句話介紹

ForgeMind 是以 MCP 為介面的遊戲引擎控制平台：透過 MCP 協定把 Unreal Engine 的專案管理、資產讀取、啟動 / 建置 / 編輯器操作開放給 AI 用戶端，讓 AI 像操作工具一樣操作引擎。

## 核心亮點

- **原生 MCP 接入**：標準 MCP 協定（HTTP / stdio），主流 AI 用戶端開箱即用。
- **可自建開源切片**：公開倉庫包含宿主、全部開源外掛、範例 UE 專案與測試，Apache-2.0，可自建可擴充。
- **引擎介面卡架構**：宿主與引擎經本機 TCP 橋解耦，可擴充至 UE 以外的引擎。
- **離線資產讀取**：不開編輯器即可解析 `.uasset` 結構；結合掃描索引（SPK）提供知識檢索能力。
- **外掛式能力注入**：宿主只內建最小工具集，能力由外掛擴充，邊界清晰可裁剪。

## 商業版（一句話）

商業版在 OpenSource 之上提供 DSL 資產產生、商業授權能力與企業支援；DSL 語法細節與授權條款請聯繫發佈方。

## 對外紀律

- 不承諾未發佈的功能；路線圖以 `roadmap.md` 為準。
- 不貶低同類工具；不公開商業模組內部（授權演算法、DSL 內部 IR 規則等）。
- 涉及原始碼行為一律以公開切片為準，不確定項標註「待確認」。
