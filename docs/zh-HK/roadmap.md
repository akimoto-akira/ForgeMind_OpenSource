# ForgeMind 路線圖

方向按公開視角陳述，按里程碑排序；具體排期以發佈為準。

## 近期

- **開源切片完善**：完成建置腳本與一鍵聯調說明，降低新貢獻者上手成本。
- **文檔同步**：隨原始碼變更維護 `docs\zh-CN\` 各文件，與公開切片保持一致。
- **測試覆蓋**：擴充 `ForgeMind.PublicTests` 與 `ForgeMindServerTest` 案例（橋命令、掃描、SPK 邊界場景）。

## 中期

- **引擎介面卡擴充**：在既有 UE 介面卡（5.0–5.8）基礎上探索更多引擎 / 編輯器接入（同構橋協定）。
- **掃描與知識能力增強**：提升 DocumentEngine 對標頭檔 / 藍圖 / 規則檔的解析覆蓋，改進 SPK 打包效率與增量更新。
- **外掛生態**：完善外掛 API 與 manifest 規範，支援更豐富的第三方工具外掛生態。

## 長期

- **開源 DSL 使用文檔**：商業 DSL 穩定後，按產品策略公開部分使用文檔、示例與教學內容；DSL 實作、Translator、IR 規則與資產產生邏輯仍為商業模組。
- **平台化**：把 ForgeMind 定位為多引擎通用 MCP 控制平台，沉澱引擎無關的協定與抽象層。

> 商業版方向（授權體系、企業支援等）不在本公開路線圖展開，請聯繫發佈方。
