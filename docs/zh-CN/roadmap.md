# ForgeMind 路线图

方向以公开视角陈述，按里程碑排序；具体排期以发布为准。

## 近期

- **开源切片完善**：补齐构建脚本与一键联调说明，降低新贡献者上手成本。
- **文档同步**：随源码变更维护 `docs\zh-CN\` 各篇目，确保与公开切片一致。
- **测试覆盖**：扩展 `ForgeMind.PublicTests` 与 `ForgeMindServerTest` 用例（桥命令、扫描、SPK 边界场景）。

## 中期

- **引擎适配器扩展**：在现有 UE 适配器（5.0–5.8）基础上，探索更多引擎 / 编辑器接入（同构桥协议）。
- **扫描与知识能力增强**：提升 DocumentEngine 对头文件 / 蓝图 / 规则文件的解析覆盖，改进 SPK 打包效率与增量更新。
- **插件生态**：完善插件 API 与 manifest 规范，支持更丰富的第三方工具插件。

## 长期

- **DSL 使用文档开放**：在商业 DSL 稳定后，可根据产品策略公开部分使用文档、示例与教学内容；DSL 实现、Translator、IR 规则及资产生成逻辑仍属于商业模块。
- **平台化**：把 ForgeMind 定位为多引擎通用的 MCP 控制平台，沉淀引擎无关的协议与抽象层。

> 商业版方向（授权体系、企业支持等）不在此公开路线图内展开，请联系发布方。
