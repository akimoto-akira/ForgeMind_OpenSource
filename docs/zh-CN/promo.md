# ForgeMind 对外宣传

## 一句话介绍

ForgeMind 是以 MCP 为界面的游戏引擎控制平台：把 Unreal Engine 的工程管理、资产读取、启动 / 构建 / 编辑器操作开放给 AI 客户端，让 AI 像操作工具一样操作引擎。

## 核心亮点

- **MCP 原生接入**：标准 MCP 协议（HTTP / stdio），主流 AI 客户端即连即用。
- **开源切片可自建**：公开仓库含宿主、全部开源插件、示例 UE 工程与测试，Apache-2.0 可自行构建与扩展。
- **引擎适配器架构**：宿主与引擎通过本地 TCP 桥解耦，可扩展到 UE 之外的引擎。
- **离线资产读取**：无需打开编辑器即可解析 `.uasset` 结构，配合扫描索引（SPK）提供知识检索能力。
- **插件化能力注入**：宿主只内置最小工具集，能力由插件扩展，边界清晰、可裁剪。

## 商业版（一句话）

商业版在 OpenSource 基础上提供 DSL 资产生成、商业授权能力与企业支持；DSL 语法细节与授权方式请联系发布方。

## 对外纪律

- 不承诺未发布功能；路线图以 `roadmap.md` 为准。
- 不贬低同类工具；不对外披露商业模块内部实现（授权算法、DSL 内部 IR 规则等）。
- 涉及源码行为一律以公开切片为准，不确定事项标注「待确认」。
